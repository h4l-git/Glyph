Privacy Policy

Last updated: 2 October 2026

Glyph is a Chrome extension that identifies the font used in text on a webpage. This page explains what data Glyph accesses, stores, and sends, and why.

What Glyph accesses

  • Page content, only when you start a tool or enable text selection. Glyph only reads or captures anything from a page after you click "Snip tool", "Image Selector", or "Highlight text" in the popup, use a keyboard shortcut, or turn on "Show card on text selection" in Settings. With that setting off, it does not run in the background or read pages automatically.
  • Snip tool: captures a screenshot of the region you select, so the image can be sent to WhatFontIs for font identification. If Sharper snip is on, Glyph briefly zooms that tab so the letters are drawn larger, captures the screenshot, then restores your previous zoom. If you selected a Claude model, WhatFontIs can't separate the letters, and you have saved an Anthropic API key, that same crop is also sent to Anthropic.
  • Image Selector: reads the picture you click, including an image, a canvas, or a picture used as a background, and prefers a larger version than the one drawn on the page, so that file can be sent to WhatFontIs. To read it, Glyph may request the picture from the site that hosts it. That request tries without cookies first, and retries with that site's cookies only if the file still cannot be read. If you have allowed Glyph to run on websites, the extension may fetch the same picture the same way. Those cookies stay with the site that hosts the picture. They are not sent to WhatFontIs or Anthropic. If the file still cannot be read, Glyph sends the picture's web address instead, and WhatFontIs fetches it. If you selected a Claude model, WhatFontIs can't separate the letters, and you have saved an Anthropic API key, the picture is also sent to Anthropic.
  • Highlight text: reads the computed CSS (font family, weight, size) of the element you click. This never leaves your device - it's shown directly in the result card.
  • Text selection (optional): if you enable it in Settings, Glyph reads the computed CSS of text you highlight with your cursor and shows the same result card. Chrome will ask for permission to run on websites you visit. You can turn this off at any time.

What Glyph stores

Glyph stores the following locally on your device using Chrome's storage API. None of this is synced to any account or server we control:

  • Your Anthropic API key, if you choose to add one
  • The Snip identification model you choose (WhatFontIs, or a Claude model)
  • Your light/dark theme preference
  • Which corner the window opens in, and its size if you resize it
  • Whether "Show card on text selection" is enabled
  • Whether "Save font history" is enabled
  • Whether "Sharper snip" is enabled
  • Whether the saved and recent lists in History are collapsed
  • How many Snip and Image Selector identifications you have used today, and which UTC day that count belongs to
  • Recent font identifications, while saving is on (up to 20): the font details, a short text sample, the page address and title, a cropped preview of the region or picture, and a WhatFontIs page link when the match includes one
  • Fonts you save from History (up to 50), which stay on this device until you remove them
  • A short local cache of font-source lookups (family name → official page URL) and catalog indexes, used only to resolve download/specimen links

Keyboard shortcuts are kept by Chrome in its own shortcut settings. Glyph only reads them to show the current Snip and Highlight text shortcuts.

What Glyph sends, and to whom

When you use the Snip tool, the cropped image is sent to WhatFontIs (www.whatfontis.com) with Glyph's own API key, which is built into the extension, so WhatFontIs can match the letterforms against its catalog. Image Selector sends the picture file you clicked, or, if that file cannot be read, the picture's web address so WhatFontIs can fetch it. You do not provide that key. The extension sends the request itself; the webpage does not receive it. This only happens when you actively use Snip or Image Selector, and only within the 20 identifications those tools share each UTC day. If you selected a Claude model, WhatFontIs can't separate the letters, and you have saved an Anthropic API key, Glyph also sends that image with your Anthropic key and the Claude model you selected to Anthropic (api.anthropic.com). History, saved fonts, page addresses, the daily count, and preview images stay on your device and are not uploaded. The one exception is Image Selector: when the picture file cannot be read, Glyph sends that picture's web address to WhatFontIs. When you open a font preview in History, Glyph may also load that typeface from Google Fonts (their official stylesheet) so it can show a live text sample; installed and generic fonts are rendered locally and nothing is fetched.

When Glyph shows a result, it may also query public font catalogs to find an official specimen or download page for the identified family. Those requests send only the font family name - not the page you were viewing, screenshots, or other browsing data. Glyph may contact:

  • Google Fonts (fonts.googleapis.com) - to check whether the family is listed there
  • Fontsource (api.fontsource.org) - to look up an official Fontsource page
  • Fontshare (api.fontshare.com) - to match the family against Fontshare's catalog
  • Adobe Fonts (fonts.adobe.com) - to check for an official Adobe Fonts page
  • Font Squirrel (www.fontsquirrel.com) - to check for an official Font Squirrel page

If no official page is found, Glyph hides the link. Glyph does not sell, share, or use your data for advertising, and does not track your browsing activity.

Permissions

  • activeTab - lets Glyph run its tools in the tab you're viewing, only after you click the toolbar icon, start a tool, or use a keyboard shortcut.
  • scripting - lets Glyph inject the Snip, Image Selector, and Highlight text overlays into the page on demand.
  • storage - lets Glyph save your settings, font history, saved fonts, the daily identification count, and the font-source cache locally, as described above.
  • Access to WhatFontIs - lets Snip and Image Selector send the image with Glyph's API key, as described above.
  • Access to Anthropic - lets Snip and Image Selector send the image with your Anthropic API key when you selected a Claude model and WhatFontIs can't separate the letters, as described above.
  • Access to font catalog sites - lets Glyph resolve an official page for an identified font, as described above.
  • Optional access to websites - requested if you enable "Show card on text selection", and the first time you use Image Selector, so Glyph can read picture files the page does not expose directly. If you decline, Image Selector still sends pictures it can read, and public picture addresses.
